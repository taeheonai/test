# 물방울 테트리스

줄을 완성하면 블록이 제 색깔의 물방울로 터져 흩어지는 테트리스. 빌드 도구 없이
브라우저에서 바로 열면 실행됩니다.

## 두 가지 버전

| | 실행 | 용도 |
|---|---|---|
| `index.html` + `style.css` + `script.js` | `index.html`을 브라우저에서 열기 | 게임 로직을 읽고 고치기 좋은 분리 구조 |
| `droplet-tetris.html` | 파일 하나를 브라우저에서 열기 | 링크 하나로 공유·배포하는 단일 파일 |

단일 파일 버전은 분리 버전과 게임 로직이 같고, 여기에 모바일 터치 조작, 마지막
소거 이름(싱글/더블/트리플/테트리스), 일시정지 버튼, 고해상도 화면 대응이 더해져
있습니다. **두 버전은 각각 관리되므로 게임 로직을 고칠 때는 양쪽 모두 반영해야
합니다.**

## 조작

| 키 | 동작 |
|---|---|
| ← → | 좌우 이동 |
| ↓ | 빠르게 내리기 |
| ↑ | 회전 |
| Space | 즉시 낙하 |
| P | 일시정지 |

좁은 화면에서는 단일 파일 버전에 터치 버튼이 나타납니다.

## 점수

한 번에 지운 줄 수에 따라 100 / 300 / 500 / 800점을 받고, 현재 레벨을 곱합니다.
10줄마다 레벨이 오르고 블록이 떨어지는 속도가 빨라집니다 (최소 100ms).

## 물방울 효과

`spawnDroplets()`가 지워지는 칸마다 물방울 5~8개를 만듭니다. 물방울은 그 칸의
블록 색을 그대로 물려받고, 중력을 받으며 벽과 바닥에서 튕기고, 진행 방향으로
늘어나 물방울처럼 보입니다. 바닥에 닿으면 감쇠가 빨라져 고이지 않고 사라집니다.
지워진 줄 자리에는 그라데이션 섬광이 함께 번쩍입니다.
